 🐍 Desafio 02 — Terminal em Python

A ideia do desafio foi recriar alguns comandos básicos de terminal usando Python, praticando funções, manipulação de arquivos, diretórios e tratamento de erros.

##  Comandos disponíveis

* `ls` — lista os arquivos e pastas do diretório atual.
* `cat` — mostra o conteúdo de arquivos.
* `echo` — exibe uma mensagem no terminal.
* `tee` — escreve um texto em um arquivo, podendo substituir ou adicionar conteúdo.
